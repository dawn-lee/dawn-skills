# 竞彩玩法规则（sporttery.cn 官方核实 2026-08-02）

## 玩法种类（4种主玩法 + 让球变体）
- **胜平负**（1X2）：90分钟胜/平/负，含让球变体（主队让1球=主队-1）
- **比分**（CRS）：90分钟具体比分，**31个选项**（主胜13个到5:2+"胜其他"，平局4个 0:0/1:1/2:2/3:3+"平其他"，主负13个到2:5+"负其他"）
- **总进球数**（TTG）：0/1/2/3/4/5/6/7+，8个选项
- **半全场胜平负**（HAFU）：9种（胜胜~负负）
- 注：官方说"4种玩法"，让球胜平负算胜平负变体。**比分盘只开主队视角**（客胜比分要自己换视角：0:3=主队0客队3，看主负档）

## 过关（串关）上限
| 玩法 | 最多几关 |
|---|---|
| 胜平负 / 让球胜平负 | **8场** |
| 总进球数 | 6场 |
| **比分 / 半全场** | **4场** |
| 混合过关 | 按各玩法上限（比分+半全场混合最高6关） |

- **自由过关**（M串N）：支持彩民自己选打几串（2串1~8串1），系统自动组合展开
- **混合过关**：允许，同场次不同玩法可混、不同运动也可混
- **胆拖：不支持**
- 同一张票所有过关关数必须一致

## M串N 注数结构（组合数学）
- **4串11** = 6×2串1 + 4×3串1 + 1×4串1 = **11注**（容错：中2场回1注2串1）
- **4串15** = 4×单关 + 6×2串1 + 4×3串1 + 1×4串1 = **15注**（含单关）
- **4串5** = 4×3串1 + 1×4串1 = 5注（中3才有）
- 3串 = 3×2串1 + 1×3串1 = 4注；5串 = 10+10+5+1 = 26注
- 注数 = 组合数 C(M, 关数) 累加

## 单关（单场投注）—— 不是所有场次/玩法都能单关
- 官方规则：**单场投注用浮动奖金，过关用固定奖金**；是否开放单关"视当期该游戏规则与场次安排而定"
- **FDP 实测（2026-08-02 快照）**：让球 14/14 不可单关；胜平负仅 4/14 可单关；比分/半全场/进球数 14/14 可单关
- 所以"008 胜平负不能单买"= 该场该玩法 `bettingSingle=0`，只能串关

## 奖金 / 返奖
- **返奖率：销售额的 69%**（68%奖金 + 1%调节基金）
- 过关奖金 = 各场固定奖金相乘 × 注数（2元/注）；以投注时刻固定奖金为准
- 单关（单场）用浮动奖金：单注奖金 = 2元 × 该场总投注÷中奖总投注×68%
- 固定奖金（过关）单注上限：2-3场20万、4-5场50万、6场+100万；单场（浮动）上限500万

## 下单前必查
1. **选串前先查每场该玩法的 `bettingSingle`（FDP rawData 快照）**——胜平负常有场次不能单关
2. **比分/半全场最多串4场** → 比分容错串上限就是 4串11/4串15
3. **返奖率 69%** 与竞彩足球 1X2 超额率 ≈12.9%（返还 88.6%）**不同**——69% 是官方返奖基准，88.6% 是赔率池内含水比，两者口径不同别混
4. 比分客胜视角换算：竞彩只开主队视角，买客胜比分用"主负档"的 0:1/0:2/1:2/0:3/1:3/2:3/"负其他"

## 命中优先执行口径

- 先检查实际 `bettingSingle`：有合格单关时优先单关；没有才做最短 2串1。
- 同场复式选择两个互斥结果时，单场覆盖概率为两者概率和，但每个额外选项都会展开组合数；必须报告真实注数与成本。
- 串票估计命中率按各场保守概率连乘；3+ 串不能标“高命中主方案”。
- 单腿命中但整张串票未兑付时，只计 `leg_hit`，不计 `ticket_hit`。
- CRS、精确 TTG 和 HAFU 的可售单关不等于高命中；经过校准且 `pool_allowed=true` 时可与 HAD/HHAD 一起参加 `return_pool` 计算，否则放娱乐区或标不可用。

## 完整串关覆盖盈利

- 用户接受为覆盖增加成本时，每场可选1-2个同玩法、同盘口线的互斥结果，再对不同比赛做完整串关；注数是各场选项数的乘积，不以单一“复式命中率”隐藏成本。
- 每个覆盖结果只命中笛卡尔积中的对应一注；该分支净收益必须用其固定奖金返还减去整票全部组合成本。
- 正式覆盖盈利票必须逐分支核验：票级覆盖概率达标、所有覆盖分支达到利润目标且整体期望净收益为正。覆盖概率用保守口径，期望净收益用独立或经校准的模型概率；两者不得混为同一市场反推概率。只做到“覆盖命中”或“部分分支盈利”均不得称稳健盈利。
- 单关使用浮动奖金，显示赔率不能证明固定盈利；确定性分支盈利口径仅适用于允许过关且已经锁定投注时固定奖金的票。
- 增加每注倍数只同比放大成本和返还，不改变组合命中率、EV或ROI。

## 四场收益覆盖池（过 2/3 关）

- 4 场各取 1 个实际在售选项，玩法可相同或跨 HAD/HHAD/TTG/CRS/HAFU 混合；同一场只取一个选项。分别购买全部 2串1 与 3串1时：`C(4,2)+C(4,3)=6+4=10` 注，2元/注共 20 元。
- 下单前逐腿检查官方快照中的 `poolStatus=Selling` 与 `bettingAllup=1`；选择的最大关数不得超过最严格腿的玩法上限。停售/不可过关时直接阻断。
- 过关奖金使用投注时固定奖金。理论返还计算必须应用单注奖金上限：2-3场20万元、4-5场50万元、6场及以上100万元；展示的是理论值时必须明确标注。
- 仅买全部 2串1为 6 注/12 元；它与 2+3 关拥有相同的“至少中2”概率，但恰中2时回本门槛更低。增加3关只提高三中/四中回报。
- 若采用 4串11，还会多 1 注 4串1，总成本 22 元；必须区分这两种票型。
- 恰好中 2 场时只有对应的 1 注 2串1 中奖。2/3关结构的净收益为 `2×两场赔率乘积−20`，所以“中2即盈利”要求这 6 组任意可能命中对的赔率乘积都大于 10；不能只看最高的一对。
- 只有 6 组恰中两场净收益全部大于 0 时才能写“中两个就赚”；若部分组合不能覆盖成本，应写“仅特定两腿组合盈利”。
- 恰好中 3 场时会命中 3 注 2串1 + 1 注 3串1；4 场全中时 10 注全中。应按所有命中状态枚举总奖金和盈利概率。
- 这是低投入、带二中容错的收益结构，不得与“单张 3串1/4串1”混为一谈，也不得标成高命中。胜平负等低赔玩法若二中无法覆盖成本应自然淘汰，高赔率玩法也必须接受概率和红旗检查。
