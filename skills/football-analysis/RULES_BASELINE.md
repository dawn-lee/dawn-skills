# RULES_BASELINE — football-analysis

> 本文件随 `football-analysis` skill 一起安装和迁移，是当前生效规则的权威快照。
> 本 skill 只做分析；投注层口径另见 `football-betting/RULES_BASELINE.md`（共享口径副本）。
> 冲突处理：模型/比分/伤停等共享口径以本文件为准；投注执行口径以 betting 文件为准。
> 变更流程：先改本文件 → 再改 SKILL/reference → 再写 `changelog/`。

## 2. 方向与概率

| 规则 | 当前值 | 状态 | 证据 |
|---|---|---|---|
| 方向表述 | 必须明确“主选 + 防”；禁止无主次的“微偏X” | active | 2026-08-07 复盘 |
| 防的选择 | 平通常是第二覆盖方向；必须同时报告防平召回率、精确率和组合成本，不宣称独立 edge | active | 历史统一审计 |
| 主选/防选概率视图 | AnalysisResult 必报 model/market/conservative 的主选、防选及覆盖概率；防平仍只是覆盖，不自动形成投注 | active | 输出契约结构 |
| 弱主胜坑 | **<40% 才是真坑**；40-60% 按隐含对待 | active | 50,206 场 |
| 弱热 40-60% | 单关/主推无 EV；可作串关方向腿（非锚） | active | 08-08/08-09 复盘 |
| 强热主队 | 可提高方向命中率；竞彩低赔通常负 EV，命中目标与价值目标分开 | active | 154,574 场 fdcouk + 竞彩 EV 回测 |
| 方向置信低 | 主胜去水接近 50% 且平局≥30%；主胜-平距 <20pp 标“方向置信低”，>25pp 才“方向明确” | active | 2026-08-13 |
| 星级含义 | 星级只表示证据收敛，不对应未经校准的命中概率 | active | 历史星级未呈单调校准 |
| 星级≥4主客拆分 | ≥⭐⭐⭐⭐ 必须过主客拆分关；主客同档/五五时整体战绩不得单独支撑最高档 | active | 流程约束 |
| gap 方向 | `gap = fair_soft(fav) - fair_sharp(fav)`；gap>0 超买，gap<0 低估 | active | 协议 |
| gap 用途 | 仅描述价格差并供 betting 标注成本；不翻转实力方向，gap<−3% 暂不视为独立 edge | active | 历史审计 + 回测方法待修 |
| 无真 sharp | `gap=null`；禁止“sharp 已校准” | active | 硬闸 |
| 热门概率校准 | 只在同一公司、同一时点和同一概率档内报告；旧 57.7/73.7/81.6 混合口径不再使用 | active | 2026-08-18 历史审计 |
| 市场复核 | 必报快照数、质量、基准/最新 H-D-A 与 `delta_pp`；少于5个跨时段快照不得称趋势 | active | 时序与表达结构 |
| 中熵置信硬闸 | `strength.direction=split/draw`，或所选主方向（home/away）对应的去水市场概率 `<60%` 时，`strength.confidence` 必须为 `low` | active | 输出契约结构审计 |
| Ensemble 结构 | 必报 poisson/xg/market 三路方向票、计数和共识；缺失模型显式为 null，不得用 `2:1` 等可与比分混淆的字符串 | active | 输出契约结构审计 |
| 翻盘协议 | `direction_flips>0` 必须逐次携带 `flip_basis`：typed 依据（xg_regression/injury/market_move/lineup_change/other）、翻盘前后方向、市场是否同意翻后方向、证据摘要；缺字段拒绝锁定。协议只管可追溯，不预设翻盘对错 | active | 结构合同：2026-08-20 周三复盘（004/005 无协议翻盘 1/2） |
