# Superseded Rules — football-analysis

> 被替代的旧口径，保留用于审计。执行时以本 skill 的 `RULES_BASELINE.md` 和 `SKILL.md` 为准。

## 1. 比分带 Top5（旧）→ Top8 + U2.5 预筛（新）

- 旧：比分只做 Top5（约 56.1%），Top1 不做。
- 新：泊松 Top8（68.5%）+ U2.5 去水 ≥60% 预筛；Top1 只作统计，不作投注。
- 证据：24,689 场 Pinnacle 回测，Top8 较 Top5 +18pp。

## 2. 弱主胜 <60% 真坑（旧）→ <40% 真坑（新）

- 旧：非热门主胜（去水 <60%）实际仅 31.5%，系统性高估。
- 新：<40% 真坑（26.8% vs 隐含 ~35%）；40-60% 档 44.6-56.4%，按隐含对待。
- 证据：50,206 场大样本验证（2026-08-08）。

## 3. H2H 短克星触发降档（旧）→ 短克星不触发（新）

- 旧：H2H 克星作为强弱反向红旗，方向降档；并作为比分规律失效前提。
- 新：H2H≤3 短克星无效应，按 `variance_up`；仅 H2H≥4 且近 3 场 0 胜长期克星轻微降档（λ_home×0.9、降深度一档）。
- 证据：154,574 场 fdcouk 回测（2026-08-13）。

## 4. λ 只用 1X2 反推（旧）→ TTG/OU 优先校准 λ_total（新）

- 旧：泊松 λ 从 1X2 赔率反推即可。
- 新：λ_total 优先从 TTG/OU 反推；与 1X2 反推差 >0.4 球时以 TTG/OU 为准。
- 证据：2026-08-15 大比分轮次团灭复盘。

## 5. 体彩官方伤停最高优先级（旧）→ 球队官网最高（新）

- 旧：伤停/停赛以体彩官方为准。
- 新：球队官网/官方公告最高；体彩官方接口只作线索，必须官网复核。
- 证据：Ure/Hansen 漏报、葡国民跨赛季残留（2026-08-10）。

## 6. 比分 Top1 作为投注建议（旧）→ 仅统计口径（新）

- 旧：存在按 Top1 单吊比分的做法。
- 新：默认交付完整比分带；单点只标 `guess`，不得放入重仓串关。
- 证据：单点概率 14-19%，三场 Top1 全中先验≈0.4%。

## 7. 星级直接映射命中概率（旧）→ 星级只表示证据收敛（新）

- 旧：★★★★★=90-100%、★★★★☆=75-89% 等。
- 新：星级只表达证据收敛；真实命中概率由 `plays.candidates.conservative_prob` 单独给出并做历史校准。
- 证据：历史星级分层未呈稳定单调关系（2026-08-18 统一审计）。

## 8. gap<−3% 视为唯一正 edge（旧）→ 价格特征待重验（新）

- 旧：gap<−3% 可作为方向/加仓核心信号。
- 新：gap 只描述 soft/sharp 价格差，不翻转实力方向；需在相同 sharp 概率档内并按实际赔率 ROI 重验后才能称 edge。
- 证据：现有回测只比较原始兑现率，未控制热门强度，近3季效应显著收窄。

## 9. 固定战术 λ 倍数直接覆盖（旧）→ 敏感性情景（新）

- 旧：识别大巴后直接 λh×0.6-0.7、λa×1.5-2.0。
- 新：只有官方表态、确认阵型或稳定历史风格才建立该敏感性情景；中心 λ 仍由市场与数据校准。
- 证据：2026-08-17 同批出现“铁桶压进球”正例与 0:7 反例。
