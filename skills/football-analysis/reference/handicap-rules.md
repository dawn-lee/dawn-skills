## 核心原则

每一次让球选择，都必须对照预测比分逐条核验。
让球结果 = 主队比分加上让球数后，与客队比分比较。

**公式**：`主队比分 + 让球数 对比 客队比分`

- 若 `主队比分 + 让球数 > 客队比分` → 让球 **胜**
- 若 `主队比分 + 让球数 = 客队比分` → 让球 **平**
- 若 `主队比分 + 让球数 < 客队比分` → 让球 **负**

## 主队让球（负让球）

主队是热门时，让球数为负（如 -1、-2）。

### 主-1（主队需赢 2 球以上才是让胜）

| 实际比分 | 计算（主+(-1)） | 让球结果 |
|----------|-----------------|----------|
| 2:0 | 1:0 | 胜 |
| 3:0 | 2:0 | 胜 |
| 3:1 | 2:1 | 胜 |
| 2:1 | 1:1 | 平 |
| 1:1 | 0:1 | 负 |
| 1:2 | 0:2 | 负 |
| 0:1 | -1:1 | 负 |

### 主-2（主队需赢 3 球以上才是让胜）

| 实际比分 | 计算（主+(-2)） | 让球结果 |
|----------|-----------------|----------|
| 3:0 | 1:0 | 胜 |
| 4:0 | 2:0 | 胜 |
| 3:1 | 1:1 | 平 |
| 2:0 | 0:0 | 平 |
| 2:1 | 0:1 | 负 |
| 1:0 | -1:0 | 负 |

## 主队受让（正让球）

主队是弱势方时，让球数为正（如 +1），表示主队获得一球优势。

### 主+1（主队平或胜为让胜；输 1 球为让平）

| 实际比分 | 计算（主+(+1)） | 让球结果 |
|----------|-----------------|----------|
| 2:2 | 3:2 | 胜 |
| 1:0 | 2:0 | 胜 |
| 0:0 | 1:0 | 胜 |
| 1:2 | 2:2 | 平 |
| 0:1 | 1:1 | 平 |
| 1:3 | 2:3 | 负 |
| 0:2 | 1:2 | 负 |

**常见错误**：把"主+1 让胜"配到比分"1:2"（客胜 1 球）。这是**错的**——1:2 + 1 = 2:2，是让球**平**，不是胜。"主+1 让胜"要求主队平或主胜。

## 平手盘（让 0）

无调整。让球结果 = 实际结果。

## 核验清单

交付任何预测表前，逐行核验：

1. 写下让球数（如 -1、+1、0）
2. 写下每个预测比分（如 2:1、1:1）
3. 对每个比分计算 `主队比分 + 让球数`
4. 与客队比分比较 → 判定让球结果
5. 确认表中让球结果与计算结果一致
6. 若发现不一致 → 修正让球选择或比分二者之一

## 实例演算

### 实例 1：收敛
- 比赛：纳什维尔 vs 亚特兰大
- 让球：-1
- 预测比分：2:1、2:0
- 核验：2+(-1)=1 = 1 → 平；2+(-1)=1 > 0 → 胜
- 让球选择：-1 胜/平 → **一致**

### 实例 2：混合（双选）
- 比赛：弗鲁米嫩塞 vs 布拉甘蒂诺
- 让球：-1
- 预测比分：1:0、1:1
- 核验：1+(-1)=0 = 0 → 平；1+(-1)=0 < 1 → 负
- 让球选择：-1 平/负 → **一致**

### 实例 3：错误（必须修正）
- 比赛：洛杉矶银河 vs 洛杉矶FC
- 让球：+1
- 预测比分：2:2、1:2
- 核验：2+1=3 > 2 → 胜；1+1=2 = 2 → 平
- 让球选择必须是：+1 胜/平（不能只选 +1 胜）
- 若只选"+1 胜" → 比分必须只保留 2:2（去掉 1:2）
- 若保留两个比分 → 让球必须是"+1 胜/平"

### 实例 4：深盘失败（真实案例，警示）
- 比赛：博德闪耀 vs 腓特烈斯塔，挪超 2026-07-18
- 让球：-2（主队需赢 3 球以上）
- 预测：3:0、4:0 → 让胜
- **实际结果：1:0** → 1+(-2)=-1 < 0 → 让球**负**
- 哪里错了：把赛季均值 xG 2.91 当成单场保证。腓特烈斯塔摆大巴（5-4-1），门将打出职业生涯最佳一战，博德多次单刀不进，唯一进球是点球。
- **教训**：让-2 或更深时，默认"平/负"（赢 2 球或更少），除非压倒性证据支持让胜。54% 的市场支持率**不构成**压倒性证据。见 SKILL.md Pitfall #9。

## 深盘默认立场（让-2 或更深）

深盘（主-2 或更多）要求热门赢 3 球以上。这是**极端结果**，不是强队的默认产物。按此决策树判断：

1. 弱势方是否保级压力大、或大概率摆大巴？
   → 是：默认让球**平/负**（赢 0-2 球）
2. 热门的 xG 是否基于开放对攻比赛、而非破大巴？
   → 不确定：默认让球**平/负**
3. 让胜的市场支持率是否低于 65%？
   → 是：不要标"稳胆"，最多 ★★★，且双选
4. 对手门将的近期状态是否调研过？
   → 否：不推荐深盘让胜
5. H2H 净胜球是否多为 1-2 球（而非 3+）？
   → 是：默认让球**平/负**

只有**以下全部成立**时才推荐深盘让**胜**：
- xG 3.0+ 且对手 xGA 2.0+
- 对手打开放足球（非摆大巴）
- 对手门将缺阵或状态差
- H2H 净胜球持续 3+
- 市场支持率 65%+
- 天气有利于进球（非雨/风影响进攻）

### 客胜比分视角换算
竞彩比分盘（CRS）**只开主队视角**。买客胜比分要用"主负档"换视角：
- 客胜 1:0 = 主负档 0:1；客胜 2:1 = 主负档 1:2；客胜 3:2 = 主负档 2:3
- 客胜 1:0 / 2:0 / 2:1 / 3:0 / 3:1 / 3:2 + "负其他"

### 玩法上限
| 玩法 | 最多几关 |
|---|---|
| 胜平负 / 让球胜平负 | 8场 |
| 总进球数 | 6场 |
| 比分 / 半全场 | 4场 |
