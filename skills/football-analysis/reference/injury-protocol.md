# 伤停/停赛采集与模型调整协议

> 权威口径：**球队官网/官方公告 > 体彩官方线索 > fotmob/库 Injury > 聚合站**。
> 主协议只保留三行硬规则；完整采集步骤在本文档。

## 1. 默认处理

- **伤停默认 = `variance_up`**：提高方差、降低仓位，不自动翻转方向。
- 要改大小球或方向，必须注明新增的独立证据。
- 一个关键球员伤停在实力差距大时影响可能极小（LAFC 缺 Lloris 仍 3:0 赢 Galaxy）。
- 超级球星缺阵 ≠ 球队必败；区分“优势减小”和“必败”。

## 2. 来源分级

| 来源 | 等级 | 模型权重 |
|------|------|---------|
| 球队官网/官方公告（含转会离队/停赛公告） | A | 全额调整 |
| Tier-1 记者 | A- | 80% 调整 |
| 2+ 独立媒体一致 | B+ | 50-60% 调整，高影响则对冲 |
| 单一媒体/AI 预测 | C | 仅备注，不调整模型 |
| 未验证传言 | D | 忽略 |

## 3. 数据源优先级（冲突时按此定夺）

| 优先级 | 源 | 信任度 | 处理 |
|--------|-----|--------|------|
| 1 | 球队官网/官方公告（含转会离队/停赛公告） | Grade A，最权威最及时 | **直接采用**；转会谈判缺阵、停赛、临场伤病全信 |
| 2 | 体彩官方伤停接口 `getInjurySuspensionV1`（返回**有**名单） | 官方但**可滞后/可跨赛季残留** | 仅作线索，**必须官网复核**（发布会/训练报告/阵容）；未复核不得作为结论依据 |
| 3 | 体彩官方伤停接口（返回**空**） | **低信息量** | **不能当“无伤停”证据**——该接口有滞后（实测漏转会缺阵/停赛），须回退官网/其他源补齐 |
| 4 | fotmob 阵容页 / 库 Injury | 线索 | 漏“转会谈判缺阵”、“已执行停赛”、“已离队球员”（阵容页陈旧），持续伤病较准；只能佐证不能单独定论 |
| 5 | 聚合站 / 搜索传言 | 仅备注 | 不调模型 |

## 4. 冲突判定

- **官网“有” vs 体彩“空”** → 以官网为准，缺阵成立（Ure/Hansen 案例）。
- **体彩“有” vs 官网“仅 X 缺席”** → **以官网为准**；体彩名单多为跨赛季残留（葡国民 4 人案例：官网发布会称仅 2 后卫缺，体彩 4 人全健康）。体彩“有”≠权威，必须发布会/训练报告核实。
- **官网未查 + 体彩“有”** → 标“官方伤停待官网确认”、按 `variance_up` 处理，不得当确定缺阵。
- **多源一致才高置信**；单源（尤其聚合站）一律降权。

## 5. 执行步骤

0. **冻结窗口**：赛前采集至少覆盖 T-75 和 T-45，每次响应保存原始内容、请求时间、来源和比赛映射。只保留可覆盖的 Injury/Lineup 当前行不算赛前证据。
1. **体彩官方接口先跑**：`cd FDP_ROOT && tsx scripts/sporttery/_sporttery-detail.ts <matchIds>`（接口见 `reference/sporttery-official-api.md`）。
2. **球队官网必查**：关键缺阵（金靴/核心中场/主力 CB）或体彩名单非空时，逐队抓官网确认/排除；分歧以官网为准。
3. **核心球星单查**：涉及超级球星（如 Neymar/Paqueta）单独搜“停赛/伤/回归”最新消息——聚合站常漏累计黄牌停赛。
4. **同位置多伤停**：≥3 名同位置（后卫/中场）伤 → 方向降档（不只降深盘/比分）；缺阵集合并后统一应用。
5. **球星缺阵检查清单**：
   - 谁 OUT？确认具体缺阵球员
   - 谁顶上？有历史级替补 → 缺一个球星 ≠ 崩盘
   - 对手变量？对手是否也有削弱
   - 主场火力？场均 4+ 球的主场缺一人影响不大

数据闸门要区分“抓取成功且完整名单为空”与“没有抓到证据”。前者可标记为已验证空响应；后者必须是 `unavailable`，不得写“无伤停”。FotMob 单源只能证明该源的 feed 完整，对高影响缺阵仍按第 2-4 节做官方/多源复核。

## 6. 模型调整规则

- **缺阵/双线作战必须降“方向”，不只降深盘**：核心中场缺阵 / 周中欧战刚踢 / 客场大热 + 核心缺 → 直接影响“赢不赢”。
- 方向层与进球层分开处理：方向层降一档（改防平或跳过），进球层单独判（018 PSV 中场双核缺 → 2:2，大球不受中场缺影响）。
- **强主队缺核心射手 + 攻击超发挥回归（G-xG>3）叠加** → 方向降级为“不败/防平”，不只降仓位（001 Sirius 2:2 Bromma）。
- **同位置 ≥3 人伤停** → 该队方向置信降档，投注层禁入串。
