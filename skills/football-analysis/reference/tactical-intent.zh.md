# 战术意图分析（中文执行版）

> 主协议见 `../SKILL.md` 第 5 节。本文件是可执行中文参考；英文版 `tactical-intent.md` 仅作原始备份。
> 当前口径：H2H≤3 短克星不触发降档；战术红旗触发双向 λ 修正见 `red-flags.md`。

## 1. 为什么需要战术意图

知道谁上场 ≠ 知道怎么踢。确认的低位防守可能压低强队 xG，但单个赛后案例不能证明固定折扣。
案例：2026-07-18 博德闪耀 vs 腓特烈斯塔。博德 xG 2.91、联赛最强进攻，但腓特烈斯塔 5-4-1 低位防守，门将超常发挥，实际 1:0（点球）。

## 2. 大巴检测

前五项满足 ≥3 条只能形成“低位防守候选”；要进入 λ 敏感性分析，还必须满足至少一条硬证据：球队/主帅官方表态、确认首发阵型，或连续正式比赛的稳定低位风格。

| # | 触发条件 | 含义 |
|---|---------|------|
| 1 | 明显弱势（胜赔>3.0，或低 2+ 排名） | 知道打不过 |
| 2 | 客场作战 | 客场劣势 → 防守姿态 |
| 3 | 保级战（倒数 4 名，或距降级区 3 分内） | 1 分 = 生存 |
| 4 | 对手攻击力强（联赛前 3 进球或 xG） | 对攻 = 自杀 |
| 5 | 无进攻动机（不追分、不主场表演） | 摆开没有收益 |

## 3. 战术 xG 敏感性区间

| 战术场景 | 强队 xG 修正 | 弱队 xG 修正 |
|---------|-------------|-------------|
| 摆大巴/低位防守 | ×0.5-0.7 | ×0.6-0.8 |
| 开放对攻 | ×1.0 | ×1.0 |
| 弱队反击 vs 高位防线 | ×0.9 | ×1.1-1.3 |
| 必须赢（落后追分） | ×1.2-1.4 | ×0.8 |
| 德比/对抗（开放） | ×1.0-1.2 | ×1.0-1.2 |
| 无动力场 | ×0.8-0.9 | ×0.8-0.9 |

## 4. 阵型推断

1. 近 3 场阵型历史：连续 5-4-1 → 对强队大概率继续。
2. 可用人员：只有 1 名正印中锋 → 4-5-1/5-4-1；3 名中卫且边卫不足 → 3-5-2/5-3-2。
3. 主帅倾向：查 `"<主教练> tactical style formation"`。
4. 比赛情境：不能输 → 防守；必须赢 → 进攻；客场打冠军 → 默认防守，除非需追总比分。

## 5. 比赛剧本模板

- A 摆大巴：强队控球但破不了低位，弱队反击；比分 1:0/0:0，进球 0-2，让球 -1 平/负、-2 负。
- B 开放对攻：双方无压力对攻；比分 2:1/1:2/2:2，进球 3+，Over 2.5。
- C 反击陷阱：强队高压，弱队吸收后打身后；比分 2:1/1:1，进球 2-3。
- D 必须赢追击：落后方早攻，暴露防线；比分 2:1/3:1/1:2，进球 3+。
- E 无动力：轮换、低强度；比分 1:0/1:1/0:0，进球 0-2，Under 2.5。

## 6. 矛盾检查（强制）

| 战术意图说... | 但预测说... | 判定 |
|-------------|-----------|------|
| 摆大巴，少进球 | 3-4 球，Over 2.5 | 建立低 λ 情景并解释市场反证 |
| 低位防守，强队受阻 | 让-2 胜，3:0 | 降低深盘置信，保留两种情景 |
| 开放对攻 | 0-0，Under 2.5 | 建立高 λ 情景 |
| 必须赢追分 | 1:0，Under 2.5 | 检查追分和反击的高 λ 情景 |
| 无动力场 | 3:0，Over 2.5 | 检查轮换证据与市场是否支持 |

**规则：战术意图是情景变量，不是自动覆盖市场、阵容和赛季数据的万能 override。**

## 7. 快速自检

对每场比赛问三个问题：

1. 客队是否保级候选或明显弱势？
2. 主队是否联赛前 3 进攻？
3. 客队是否没有进攻动机（不追分）？

三个都“是” = 低位防守候选。只有再取得硬证据才建立强队 ×0.5-0.7 的敏感性情景；无硬证据时只加风险标签，不直接改中心 λ。
