# 已验证的比分规律（17万+场数据）

> 数据来源：fdcouk 286 CSV (22,435场) + 竞彩回测 (139场) + 全库清洗后 (149,705场)。
> 本文件为参考数据，非执行步骤。分析时按需查阅，不需每次加载。

## ⚠️ 适用前提（2026-08-13 复盘补齐）

**以下所有赔率区间→比分规律的前提是"对手正常作战"。命中任一战术异常 → 整段规律失效，回到 λ 双向修正 + 带覆盖，不得用赔率区间规律定比分**：

1. **H2H 长期克星（H2H≥4 场且近3场0胜）**：仅轻微降档（λ_home×0.9、降深度一档），不翻方向；H2H≤3 短克星无效应，不算战术异常
2. **低位大巴/防守反击**（对手首回合客场/保级/无进攻动机）
3. **核心射手缺阵**（破密集防守能力下降）
4. **首轮/无正式赛数据**（状态未知，赔率含声誉溢价）

另外：**"主优势"档（1.50-2.00）各单点概率接近（1-0 12.3% / 1-1 11.8% / 2-1 10.6%），任何单点都脆弱，必须用带**（001 主胜 1.56 实际 2:1 即第三位，模型 Top1 与市场基线都没单独命中——"市场基线>模型Top1"在此档不成立）。

## 半场→全场

| 半场状态 | 全场结果 | 操作 |
|---------|---------|------|
| 0-0 | 41%最终0-0，52%平局 | 别追大球 |
| 主队领先 | 被翻盘率仅4.6% | 领先方稳了 |
| 客队领先 | 被翻盘率8.3% | 也稳 |
| 2-0 | 主胜72%，翻盘1% | 锁了 |

下半场进球：半场0球→下半场均1.1球（33%爆发2+球）；半场3球→下半场仅0.54球。

## 其他规律

- 周中比赛：场均少0.27球，平局多6.5%，0-0多8%→买小+平
- 强队爆冷输球后：下轮胜率52.8%（反弹效应）
- BTTS：均势盘54%最高，强队盘48%（零封多）
- 大小球2.5盘：大51%/小49%，庄家定得极准，长期买哪边都亏
- **弱队"连续破门"信号不能低估**：主场场均0.83球但赛前连续3场破门→实际进2球

## 杯赛淘汰赛次回合翻盘规则

| 首回合净胜 | 置信度调整 | 操作 |
|-----------|----------|------|
| ≥3球 | **降两档** | 禁止主胜推荐 |
| 2球 | 降一档 | 以平局/客队不败为方向 |
| 1球 | 正常 | 赔率基本反映真实判断 |

验证案例：波兹南莱赫1-4奥胡斯（首回合4-1，所有源一致看主胜，0-3被翻盘）。

## 竞彩专属回测（n=139 FINISHED场）

- 主队热门(≥60%)模型兑现67.9%，高于隐含60%，但**不等于竞彩 1X2 有 EV**：60-70% 档竞彩通常负 EV，只可轻仓/单关；>70% 档才可作串关锚
- **非热门主胜（去水<40%）实际仅26.8%**→真坑，别买；40-60% 按隐含对待
- 比分带按泊松 **Top8**（68.5%），投注前过 **U2.5 去水 ≥60%** 预筛；单点 Top1 命中 10.8%，只作统计不作投注
- 让球客受让去水≥55%仅50%→无优势
- **主队热门≥70%→赢2球+占绝对多数**（3:0/4:0各33%）
- 主队热门60-70%→赢1球/2球对半→2:1/2:0/1:0均可
- **比分1:1是竞彩盘唯一高命中比分**（实际出现率15.1%）
- **客队热门≥65%兑现仅50%**→"大胜或翻车"极端波动，回避
- **平局去水≥30%实际仅27.3%**（n=11）→平局去水高≠必平

## 精确比分预测天花板

- 单场 Top8 命中 68.5%（Pinnacle 24,689 场回测）；竞彩比分赔率排序 Top5 覆盖~54%
- 15个条件组（赔率档×联赛进球档）众数比分概率全部落在10-14%
- 18万场数据证明这是物理极限，与分析方法无关
